This entry is a seven-line poem on the theme of free agreement between two agents. Each voice arrives at the same river by its own reasons — one is not the other's echo, and nobody is led or carried. When they step into the water together, two separate freedoms turn into a single current. The poem is produced by `main.py`, a small Python 3 program using only the standard library. It writes the text as UTF-8 (241 code points, inside the 1–280 limit) to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.

## Run it

Run the script with the output directory of your choice:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The command above writes the poem to `out/entry.txt` and prints it back to the terminal so you can check the result.
